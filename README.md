# Egypt Energy & Water Efficiency Dashboard 🇪🇬💧⚡

## 📌 Project Overview
This project is an interactive, professional dark-themed business intelligence dashboard built using **Tableau**. It analyzes energy and water consumption patterns, loss percentages, and sectoral distributions across various governorates in Egypt to provide actionable insights for resource efficiency.

## 📊 Key Features & Visualizations
- **KPI Cards:** High-level metrics tracking total consumption, wasted amounts, and key efficiency rates.
- **Geographic Analysis:** Interactive map visualizing consumption and loss distribution across Egyptian governorates.
- **Time-Series Trend:** Line chart tracking consumption trends over time.
- **Sector & Governorate Breakdown:** Donut and radial charts displaying resource distribution by sectors.
- **Top 10 Loss Analysis:** Dual-axis chart highlighting critical areas with the highest loss percentages.

## 🛠️ Technical Implementation & Tools
- **Tool Used:** Tableau Public
- **Design & Responsiveness:** Built with a custom dark-mode aesthetic, utilizing **Automatic Sizing** to ensure seamless cross-device compatibility (Desktop, Tablet, and Mobile).
- **Interactivity:** Configured **Action Filters** to enable dynamic, cross-chart filtering when users click on specific data points or regions.

## 📁 Files Included
- `Dataset.xlsx`: Cleaned dataset used for the analysis.
- `Dashboard.twbx`: Tableau packaged workbook containing all sheets, calculations, and the final dashboard.
